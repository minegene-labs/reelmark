# Security

## Reporting a vulnerability

Report vulnerabilities privately through **Security → Report a vulnerability** on this repository. Only the maintainer can see the report. Please don't open public issues for security problems.

Include what you found, the version, and steps to reproduce it if you can. Don't attach personal files or real names from your library.

## What happens next

- You'll get a first reply within 14 days, usually much sooner.
- A confirmed vulnerability is fixed in a new release within 60 days of the report, and sooner for a serious one.
- The release notes say which vulnerability was fixed, with its CVE if it has one, and credit you unless you'd rather not be named.

## Supported versions

Only the latest release gets security fixes.
