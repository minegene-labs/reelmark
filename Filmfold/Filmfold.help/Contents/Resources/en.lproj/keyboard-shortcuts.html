Keyboard shortcuts

ShortcutDoes
⌘OAdd Files…
⌘ReturnCopy (or Move) to Library
⌘RSearch Again… for the selected item
⇧⌘RShow the selected items in Finder
Space or ⌘YQuick Look the selected items
Delete or ⌘DeleteRemove the selected items from the list
⌥⌘DeleteClear the whole list
⌘.Stop adding files from a big folder
⌘Z / ⇧⌘ZUndo or redo the last Copy or Move to Library
⌘ASelect everything in the list
⌘FSearch the list
⌘,Settings
⌘?Filmfold Help

They're all in the File, Edit and Help menus too.
