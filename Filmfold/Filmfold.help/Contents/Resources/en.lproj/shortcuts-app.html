Use Filmfold with Shortcuts

Filmfold adds two actions to the Shortcuts app, which Spotlight can run too:

  • Add Files to Filmfold adds video files or download folders, as dragging them in does. Use it in a Finder Quick Action, or a Folder Action on your downloads folder.
  • Add Matched Files to Library waits for every file to be looked up, then copies or moves every matched file, following your choice in Settings. It reports how many were added and how many need attention.

Both actions open Filmfold and run inside it, so nothing more leaves your Mac than when you use the window.
