Undo a copy or move

Choose Edit › Undo (⌘Z) to reverse the last Copy or Move to Library:

  • Moved files go back where they came from.
  • Copies go to the Trash. The originals are never touched, and you can still get the copies back from the Trash.

Choose Edit › Redo (⇧⌘Z) to file them again.

Filmfold won't undo a file if doing so could lose something. It tells you if the file is no longer where Filmfold put it, if the original of a copy is gone (so the copy is kept), or if something else is now where the file came from.
