Filmfold Help

If something goes wrong

A file has no match

Filmfold reads the title and year from the file name. If the name is unusual, choose File › Search Again… (⌘R) and type the title yourself.

“TMDB didn't accept the access token”

Your own token was refused. Check it in Filmfold › Settings, or click Remove to use the built-in token.

“TMDB is busy” or “You're offline”

Wait a moment, check your internet connection, then choose Search Again… for the items that weren't found.

“Choose a movie folder in Settings”

Filmfold doesn't know where your library is, or lost access to it. Choose the folder again in Filmfold › Settings.

“… is already in your library”

A file with that name is already there, and Filmfold never replaces it. Remove the item from the list, or remove the old file in Finder first if you want to replace it.

macOS asks whether Filmfold may use your Keychain

This happens once after each update if you've saved your own TMDB token. Click Always Allow.
