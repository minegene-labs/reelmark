Filmfold Help

Copy or move files to your library

Click Copy to Library, or choose File › Copy to Library (⌘Return), to file every matched item at once.

Choose what happens to your downloads in Filmfold › Settings, under “When adding to library”:

  • Copy leaves the original exactly where it is and puts a copy in your library. Use it if you're still sharing the download, or want to keep it.
  • Move takes the file out of your downloads and puts it in your library. It's faster on the same disk and doesn't use extra space.

Filmfold never deletes your files, and never replaces a file that's already in your library. If a file with the same name is already there, the item says so and nothing changes.

Tidy the list

  • To remove items from the list, select them and press Delete. Your files aren't changed.
  • To empty the whole list, click Clear or choose File › Clear List (⌥⌘Delete).
  • To stop searching a big folder you added, choose File › Stop Adding Files (⌘.).
